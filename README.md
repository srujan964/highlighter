# Highlighter

A small browser source to highlight messages of importance from Twitch chat. Highlights messages tagged with `!highlight` or `!ht` from moderators by default.

## Building

Bundle the project via:

```
vite build
```

## Usage

1. Create a new browser source in OBS and point it to the path of the html file generated by Vite - `file://<path to index.html>`.
2. Configure the channel via `?channel=<name>` query param in the URL.
